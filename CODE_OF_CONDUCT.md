# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies to all project spaces: issues, pull requests,
discussions and any other place where the project is represented.

## In short

- Be respectful and considerate. Assume good faith.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.
- No harassment, personal attacks, discriminatory language, sexualised
  content, or publishing of other people's private information.

## Reporting

If you experience or witness unacceptable behaviour:

- use GitHub's **Report content** option on the comment, issue or pull
  request, or
- contact the maintainers privately through
  [Report a vulnerability](https://github.com/DevHatRo/outbound-smtp/security/advisories/new)
  and start the title with "Code of Conduct". This channel is only visible to
  the maintainers.

Reports are handled confidentially. Maintainers may edit or remove
contributions and may temporarily or permanently ban contributors whose
behaviour violates this Code of Conduct, following the enforcement guidelines
of the Contributor Covenant.
